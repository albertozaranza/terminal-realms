# CONTENT_BIBLE.md

# Terminal Realms Content Bible

Este documento define o conteúdo oficial do jogo.

Toda criatura, item, habilidade, região e chefe deve seguir estas definições.

---

# Filosofia de Conteúdo

O mundo deve transmitir:

- Fantasia medieval clássica
- Progressão constante
- Descoberta
- Perigo crescente
- Recompensas significativas

Evitar:

- Humor excessivo
- Referências modernas
- Tecnologia avançada
- Conteúdo sci-fi
